# Notebooks de Google Colab

Este directorio contiene los cuadernos de Google Colab para las sesiones del curso de Big Data.

## Cómo usar los notebooks

### Opción 1: Abrir directamente en Google Colab

Haz clic en el badge "Open in Colab" que aparece al principio de cada notebook, o usa los enlaces de la tabla.

### Opción 2: URL directa

```
https://colab.research.google.com/github/juanarrow/BigData-notebooks/blob/main/sesion-XX.ipynb
```

Reemplaza `XX` con el número de sesión (01, 02, …, 40).

## Requisitos

Los notebooks están diseñados para ejecutarse en **Google Colab** sin necesidad de instalación local. Las librerías necesarias se instalan automáticamente cuando es necesario (como PySpark).

## Librerías utilizadas

- `pandas` - Manipulación de datos
- `numpy` - Cálculo numérico
- `matplotlib` / `seaborn` - Visualización estática
- `plotly` - Visualización interactiva
- `scikit-learn` - Machine Learning
- `pyspark` - Procesamiento distribuido (sesión 15+)
- `sqlite3` - Bases de datos SQL (simulación Hive)
- `hashlib` - Checksums e integridad de datos

## Notas

- Todos los notebooks son **autocontenidos**: incluyen la creación de datos de ejemplo
- Para guardar tu trabajo: `Archivo → Guardar una copia en Drive`
